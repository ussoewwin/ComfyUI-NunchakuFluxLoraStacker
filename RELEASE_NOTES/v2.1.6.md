## Overview

This release integrates the **Use Everywhere** node family directly into this repository under `nodes/everywhere/` and frontend extension under `js/everywhere/` as a port based on the **Apache-2.0 License** (see `nodes/everywhere/LICENSE`). 

Following modern ComfyUI frontend architecture updates (1.52.7+), the upstream repository ([chrisgoringe/cg-use-everywhere](https://github.com/chrisgoringe/cg-use-everywhere)) ceased functioning due to frontend breaking changes. A dedicated fork was maintained and a Pull Request submitted to upstream, but the upstream project has remained unmaintained for three months. Following the same pattern as **Florence-2** and **ControlAltAI**, this fork has been merged directly into this pack to reduce separate-repository maintenance overhead while providing fully modernized, collision-free virtual routing and broadcasting in ComfyUI.

---

## 1. Key Features & Architectural Improvements

### 1. Collision-Free Class Namespacing (`hswq_` prefix)
All integrated node class types and display names are namespaced with the **`hswq_`** prefix to prevent class and type collisions with upstream or legacy installations:
- **`hswq_AnythingEverywhere`**: Universal broadcast node for routing any data type across the workflow
- **`hswq_SeedEverywhere`**: Dedicated broadcast node for seeds and integer randomness
- **`hswq_AnythingSomewhere`**: Targeted broadcast node routing to specific node titles or regex rules
- **`hswq_AnythingEverywhereTriplet`**: Multi-slot broadcast node for MODEL, CLIP, and VAE triplets
- **`hswq_AnythingEverywherePrompts`**: Multi-slot broadcast node for positive/negative conditioning
- **`hswq_ComboClone`**: Replicates combo widget options from connected downstream targets
- **`hswq_SimpleString`**: Legacy string pass-through utility

### 2. Modern ComfyUI Frontend Compatibility (1.52.7+)
The integrated frontend extension (`js/everywhere/`) resolves critical breaking changes introduced in recent ComfyUI releases:
- **`node.comfyClass` Deprecation**: Safe fallback resolution for class identification across LiteGraph node instances
- **`graphToPrompt` Receiver Binding**: Explicit receiver context binding to eliminate runtime execution errors
- **Dangling Link Cleanup**: Robust graph traversal and link validation preventing dangling link errors during prompt serialization

### 3. Frontend Isolation & Zero-Dependency Execution
- **CustomElement Collision Prevention**: Renamed the floating window custom element tag to `<hswq-ue-floating>` with safe existing-class fallback constructors, preventing `TypeError: Illegal constructor` crashes when multiple extensions are loaded.
- **DOM ID Namespacing**: Isolated the tooltip element to `#hswq_ue_tooltip` to avoid style and DOM conflicts.
- **Logging Stability**: Fixed unimported logger calls in `Deferred.prototype.execute` with native `console.error` handling.
- **Zero External Dependencies**: The package operates completely standalone with zero imports or runtime dependencies on `cg-use-everywhere`.
