## Overview

This release fixes the Florence-2 nodes crash under the new transformers 5.x generation-strategy validation. The Florence-2-PromptGen model `config.json` carries `forced_bos_token_id: 0`, which transformers 5.20+ no longer accepts on `model.config` at `generate()` time, raising `ValueError: You have modified the pretrained model configuration to control generation`. The model loader now strips legacy generation parameters from both the top-level config and the language-model (BART) config, and explicitly sets them on `model.generation_config` with the correct BART defaults.

---

## 1. Key Fixes

### 1. Florence-2 `ValueError` under transformers 5.x
- **Root Cause**: transformers 5.x (current 5.20.2) enforces that generation parameters (`forced_bos_token_id`, `forced_eos_token_id`, `decoder_start_token_id`, etc.) must live on `model.generation_config` - any of them left on `model.config` makes `generate()` raise `ValueError: You have modified the pretrained model configuration to control generation`.
- **Trigger**: The Florence-2-PromptGen `config.json` ships with `forced_bos_token_id: 0`, which `Florence2Config.from_pretrained()` loaded into `model.config` verbatim. Every Florence-2 task (caption, tag generation, OCR, etc.) crashed at the `generate()` call after the transformers update.

### 2. Legacy Parameter Stripping in `load_model()`
- The loader now walks `GenerationConfig._get_default_generation_params()` and sets every legacy generation attribute (except `use_cache`) to `None` on **both** the top-level `Florence2Config` and the language-model (BART) `config` before model construction.
- The values are then explicitly written to `model.language_model.generation_config` with the correct BART defaults: `decoder_start_token_id=2`, `eos_token_id=2`, `pad_token_id=1`, `forced_bos_token_id=0`, `forced_eos_token_id=2`.
- `forced_bos_token_id=0` is mandatory for BART caption generation - the defaults are applied via explicit `None` checks, since the strip itself sets those attributes to `None`.

## 2. Changes Summary

| Item | Previous (v2.1.4) | v2.1.5 |
|---|---|---|
| **transformers 5.x compatibility** | `generate()` raised `ValueError` on legacy config params | **Legacy params stripped from config; generation via `model.generation_config`** |
| **BART generation defaults** | Read from `config.json` (legacy path) | **Explicitly set: decoder_start=2 / eos=2 / pad=1 / forced_bos=0 / forced_eos=2** |
| **Verification** | Not covered | **Model load + `generate()` verified on transformers 5.20.2** |
| **Documentation** | - | **Bilingual changelog entries updated (EN / 中文)** |
