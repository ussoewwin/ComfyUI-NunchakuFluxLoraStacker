# v2.0.5 — 移除 Model Patch Loader（现于 ComfyUI-HSWQ-Loader-and-Tools 维护）

本版本从本插件中移除了 **Model Patch Loader**（`ModelPatchLoaderCustom`）。该节点已作为完全相同的节点 `HSWQModelPatchLoaderCustom` 整体移植至姊妹仓库 **[ComfyUI-HSWQ-Loader-and-Tools](https://github.com/ussoewwin/ComfyUI-HSWQ-Loader-and-Tools)**，并在该仓库持续维护（节点的开发维护由此统一至单一仓库）。本插件的其他内容不受影响——与它同处一个模块文件的 `FastGroupsBypasserV2` 保持完全不变。

---

## 1. 核心变更概览

| 项目 | v2.0.4 及以前 | v2.0.5 |
|---|---|---|
| **Model Patch Loader** | 随本插件发布（`ModelPatchLoaderCustom`，显示名 "Model Patch Loader"） | **已移除**——已完整移植至 ComfyUI-HSWQ-Loader-and-Tools（`HSWQModelPatchLoaderCustom`） |
| **CPU offload 运行时补丁** | 于 `nodes/misc_v2.py` 导入时全局安装（包装 stock `ZImageControlPatch` 的 apply 步骤） | 从本插件移除——等价补丁（`patches/model_patch_cpu_offload.py`）随 ComfyUI-HSWQ-Loader-and-Tools 提供 |
| **FastGroupsBypasserV2** | 由 `nodes/misc_v2.py` 提供 | **保持不变**——移除过程中逐字节未动 |
| **README（EN / 中文）** | 记录了 Model Patch Loader 节点 | 节点条目与章节已删除；节点列表与章节重新编号 |
| **版本元数据** | `2.0.4` | `2.0.5`（`pyproject.toml` / `__init__.py`），已发布至 Comfy Registry |

---

## 2. 移除详情 — `ModelPatchLoaderCustom`

被移除的节点是一个面向 `models/model_patches` 的模型补丁加载器，可自动识别三种架构：

- **Qwen Image block-wise ControlNet** — 判别键 `controlnet_blocks.0.y_rms.weight`
- **SigLIP multi-feature projector** — 判别键 `feature_embedder.mid_layer_norm.bias`
- **Z-Image Fun ControlNet** — 判别键 `control_all_x_embedder.2-1.weight`（Union 2.0 / 2.1，动态检测控制层数量）

并具备以下特性：

- **CPU offload**（`cpu_offload`，默认 `True`）：补丁图与其 `ModelPatcher` 均在 CPU 主内存中构建（`load_device` / `offload_device` = CPU），并通过运行时补丁让 stock `ZImageControlPatch` 的 apply 步骤对以 CPU 加载的补丁继续在 CPU 上执行。端到端 CPU 执行适用于 Z-Image Fun ControlNet 路径；Qwen block-wise 与 SigLIP projector 的 apply 节点未被补丁化。
- **ConvRot INT8 支持**：自动检测携带 `int8_tensorwise` `comfy_quant` 层的检查点，并以 `mixed_precision_ops` 构建，权重以 **INT8 形式驻留内存**（`TensorWiseINT8Layout`），前向运算走 comfy-kitchen 的 `int8_linear` 内核（含在线 ConvRot 旋转）；非量化检查点保持标准 `manual_cast` 路径。
- 输出：标准 **`MODEL_PATCH`**，配合 stock apply 节点使用（`QwenImageDiffsynthControlnet` / `ZImageFunControlnet` / `USOStyleReference`）。

本次发布从 `nodes/misc_v2.py` 中移除了节点类、其辅助模块（`BlockWiseControlBlock`、`QwenImageBlockWiseControlNet`、`SigLIPMultiFeatProjModel`）、INT8 检测与 ops 辅助函数、CPU offload 应用补丁以及节点注册。

## 3. 迁移去向（现维护位置）

该节点现随 **[ComfyUI-HSWQ-Loader-and-Tools](https://github.com/ussoewwin/ComfyUI-HSWQ-Loader-and-Tools)** 持续开发（自 v3.5.0 起提供）：

| | |
|---|---|
| **节点 ID** | `HSWQModelPatchLoaderCustom` |
| **显示名** | HSWQ Model Patch Loader (ConvRot INT8 / CPU offload) |
| **输入 / 输出** | `name`（来自 `models/model_patches` 的模型补丁）、`cpu_offload`（BOOLEAN，默认 `True`）→ `MODEL_PATCH` |
| **配合使用的 apply 节点** | stock 节点：`QwenImageDiffsynthControlnet` / `ZImageFunControlnet` / `USOStyleReference` |

移植为功能等同版本：架构分发逻辑、`cpu_offload` 行为与 ConvRot INT8 `comfy_quant` 处理完全一致。

---

## 4. 迁移指南

### 旧节点用户

1. 在 `custom_nodes` 中安装或更新 **[ComfyUI-HSWQ-Loader-and-Tools](https://github.com/ussoewwin/ComfyUI-HSWQ-Loader-and-Tools)**（通过 ComfyUI-Manager 或 `git clone`）。
2. 在工作流中，将旧的 **Model Patch Loader** 节点替换为 **HSWQ Model Patch Loader (ConvRot INT8 / CPU offload)**。
3. 在下拉菜单中重新选择模型补丁文件——文件仍来自标准的 `models/model_patches` 文件夹，`MODEL_PATCH` 输出与以往连接相同的 apply 节点。
4. 无需其他改动——磁盘上已有的模型补丁文件不受影响。

### 未曾使用该节点的用户

无需任何操作；本插件的其他内容没有变化。

- v2.0.5 版本提交通过了本仓库的 Comfy Registry 发布工作流。
