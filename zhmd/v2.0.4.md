# v2.0.4 — CCSR TensorRT 自动化安装器与依赖栈全面现代化

本版本对 CCSR TensorRT 加速管线进行了全面升级与现代化改造，引入参考自 SeedVR2 的一键式安装架构、将全部依赖统一至根目录 `requirements.txt`、更新至 PyPI 最新稳定运行时栈，并实现了引擎文件的自动流式下载与多重就绪诊断。

---

## 1. 核心改进概览

| 功能模块 | v2.0.3 及以前 | v2.0.4 |
|---|---|---|
| **一键安装** | 仅依赖 ComfyUI-Manager 或手动执行 `python install.py` | 新增根目录一键脚本 `Install TensorRT CCSR.bat` 与后台自动化 `scripts/install.ps1` |
| **依赖管理** | 依赖分散，无自动版本探测与旧版升级 | 所有依赖统一合并至根目录 `requirements.txt`；`install.py` 具备 `--no-deps` 保护及旧版 Triton 自动检测升级 |
| **Triton 运行时** | 依赖旧版或未固定 | 升级至 PyPI 最新稳定版 `triton-windows==3.8.0.post28` |
| **ONNX & TensorRT 栈** | 未严格锁定最新发布版本 | 锁定 `tensorrt-rtx==1.6.1.120`、`onnx==1.22.0`、`onnxscript==0.7.1`、`polygraphy==0.53.4` |
| **引擎分发** | 缺失时仅抛出警告并要求用户手动去 Hugging Face 下载 | `install.py` 自动流式下载 `ccsr_apply_f16io.rtxplan` 与 `ccsr_trt_aux.safetensors` 并校验文件完整性 |
| **环境验证与防护** | 节点加载时若缺少依赖直接报 Python 异常崩溃 | 新增 `scripts/verify_install.py` 全栈诊断脚本；`LoadCCSRModelTensorRT` 节点增加运行时导入防护与清晰指引 |
| **安装日志** | 仅在控制台即时输出 | 自动完整输出至 `outputs/install.log` 便于故障排查 |

## 2. 自动化安装流水线（参考 SeedVR2 架构）

为彻底解决 Windows 用户在配置 TensorRT-RTX 时的环境冲突与复杂的依赖安装流程，引入了与 SeedVR2 相同标准的高可靠自动化流程：

### 2-1. `Install TensorRT CCSR.bat` & `scripts/install.ps1`
- **自动定位 Python 环境**：优先探测当前 ComfyUI 的 `python_embeded\python.exe`、当前激活的 Virtualenv，以及系统 PATH 中的 Python。
- **环境预检**：在执行安装前验证 PyTorch 与 CUDA 运行状态（输出 PyTorch 版本、CUDA 可用性、检测到的 GPU 名称）。
- **安全依赖安装**：采用 `--no-deps` 策略安装 TensorRT 运行依赖，确保绝不篡改或破坏 ComfyUI 底层的 PyTorch 和 CUDA 驱动生态。
- **引擎自动拉取**：检测 `nodes/CCSR/trt_engines/` 下是否存在预编译引擎，缺失时自动通过 HTTP 流式拉取（支持断点续传与大小检查）。
- **终态诊断**：调用 `scripts/verify_install.py` 完成实际 TensorRT 加载与推理上下文构建测试，通过后写入 `.installed_ccsr_trt` 时间戳标记。

## 3. 依赖栈统一与现代化

所有依赖项现已完全统一合并至根目录 `requirements.txt`，消除了额外依赖文件造成的混乱：

```txt
# CCSR TensorRT upscaler stack (nodes/CCSR)
triton-windows==3.8.0.post28
tensorrt-rtx==1.6.1.120
onnx==1.22.0
onnxscript==0.7.1
polygraphy==0.53.4
```

- **`triton-windows==3.8.0.post28`**：PyPI 上最新构建的 Windows 原生 Triton 编译包，完美适配 TensorRT-RTX 1.6.1 及其 JIT 内核编译需求。
- **自动升级检测**：`install.py` 内置版本探测逻辑。如果环境中已安装旧版 Triton（如 3.5.x 或 3.6.x），会自动安全触发升级至 `3.8.0.post28`。
- **最新构建版本**：`onnx==1.22.0`、`onnxscript==0.7.1` 与 `polygraphy==0.53.4` 同步采用最新稳定发布版本。

---

## 4. 预编译引擎自动流式下载

CCSR TensorRT 放大器需要两个核心模型文件（共约 2.2 GB）：
1. **`ccsr_apply_f16io.rtxplan`**：融合了 ControlNet 与 UNet 的静态 Shape（512x512 瓦片 / 64x64 Latent）TensorRT-RTX 优化引擎。
2. **`ccsr_trt_aux.safetensors`**：伴随引擎的辅助权重（VAE 编解码器与条件文本编码器）。

在执行 `install.py` 或双击 `Install TensorRT CCSR.bat` 时，安装器会自动从 Hugging Face 仓库（`ussoewwin/CCSR-TensorRT-Engine`）流式拉取这两个文件至 `nodes/CCSR/trt_engines/`，并带有分块流式进度显示与文件完整性校验（校验文件大于 1 MB），无需手动干预。

## 6. 安装与验证指南

### 方法 1：一键批处理（Windows 推荐）
直接双击仓库根目录下的 **`Install TensorRT CCSR.bat`**。脚本会自动完成环境识别、依赖安装、引擎下载及就绪测试。

### 方法 2：ComfyUI-Manager
在 ComfyUI-Manager 中安装或更新本插件时，会自动触发 `install.py` 并在后台自动拉取引擎与配置环境。

### 随时验证运行状态
在终端或虚拟环境中运行：
```bash
python scripts/verify_install.py
```
若全部显示绿色 `[OK]`，即代表 TensorRT 加速已完全就绪，可在 ComfyUI 中正常连接 **LoadCCSRModelTensorRT** 与 **CCSR_Upscale_TRT** 节点进行高达 1.4 倍于 PyTorch 的高清图像超分辨率放大。
