# v2.1.3 — `triton-windows` 动态解析与解除版本固定

本版本移除了全仓库依赖清单、安装器脚本及文档中针对 `triton-windows` 的硬编码版本绑定（`triton-windows==3.8.0.post28`），将 CCSR TensorRT 依赖栈全面升级为动态解析最新版本。

通过解除版本锁定，环境配置与安装流水线能够自动从 PyPI 获取并安装最新版本的 `triton-windows`，完美适应 ComfyUI、PyTorch 及 CUDA 环境的持续更新，无需手动维护或重新固定版本号。

---

## 1. 核心变更概览

| 变更项 | v2.1.2 及以前 | v2.1.3 |
|---|---|---|
| **requirements.txt** | 硬编码固定为 `triton-windows==3.8.0.post28` | **`triton-windows`**（自动解析最新版） |
| **install.py** | `("triton", "triton-windows==3.8.0.post28", "3.8.0")` | **`("triton", "triton-windows" if sys.platform.startswith("win") else "triton", None)`** |
| **平台自适应** | 仅硬编码 Windows 轮子版本 | 依据 `sys.platform` 自动区分 Windows（`triton-windows`）与 Linux（`triton`） |
| **修复模式 (`--repair`)** | 强制重装特定旧版本 | 强制升级至 PyPI 最新构建版本 |
| **文档与更新日志** | 记录固定版本号 `3.8.0.post28` | 中英文 README 与 CHANGELOG 均同步为最新版说明 |

---

## 2. 变更详情

### 1. 依赖清单 (`requirements.txt`)
- 将 `triton-windows==3.8.0.post28` 更改为未锁定的 `triton-windows`。
- 允许 `pip` 在安装时自适应选择并下载适用于当前 Python 及 CUDA 版本的最新构建。

### 2. 自动化安装器 (`install.py`)
- 在 `TRT_STACK` 中，将针对 Triton 的定义重构为：
  ```python
  ("triton", "triton-windows" if sys.platform.startswith("win") else "triton", None)
  ```
- 移除了最低版本限制 `3.8.0`，在缺少包时自动拉取最新版；在 `--repair` 模式下执行 `--upgrade` 时亦自动获取最新版本。

### 3. 说明文档与多语言同步
- 同步更新 [README.md](../README.md) 与 [zhmd/README.md](README.md) 中的 TensorRT 运行时栈说明。
- 更新 [md/CHANGELOG.md](../md/CHANGELOG.md) 与 [zhmd/CHANGELOG.md](CHANGELOG.md)，并加入语言一致的发布说明链接。
