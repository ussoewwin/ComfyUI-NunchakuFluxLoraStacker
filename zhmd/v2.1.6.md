# v2.1.6 — 集成 Use Everywhere 节点（hswq_ 前缀）与 ComfyUI 前端 1.52.7+ 兼容

本版本基于 **Apache-2.0 许可证**（参见 `nodes/everywhere/LICENSE`）将 **Use Everywhere** 广播与虚拟连线路由节点家族直接集成至本仓库（位于 `nodes/everywhere/`，前端扩展位于 `js/everywhere/`）。

随着近期 ComfyUI 前端架构更新（1.52.7+），官方上游仓库（[chrisgoringe/cg-use-everywhere](https://github.com/chrisgoringe/cg-use-everywhere)）因前端破坏性变更而无法正常工作。为此，我创建并维护了包含针对性修复的分支并向上游提交了 PR，但官方已持续 3 个月完全处于搁置未维护状态。参照 **Florence-2** 与 **ControlAltAI** 的成熟模式，该分支已直接合并至本插件中，在彻底消除单独维护独立仓库负担的同时，提供完全现代化、无冲突的 ComfyUI 广播与虚拟路由功能。

---

## 1. 核心特性与架构升级

### 1. 无冲突类命名空间化（`hswq_` 前缀）
所有集成的节点类类型与显示名称均统一添加 **`hswq_`** 前缀，防止与上游或旧版安装产生命名冲突：
- **`hswq_AnythingEverywhere`**：通用广播节点，可在全图工作流中无线广播任意数据类型
- **`hswq_SeedEverywhere`**：专用随机种子广播节点，适用于整数与随机源路由
- **`hswq_AnythingSomewhere`**：定向广播节点，可指定目标节点标题或正则匹配规则
- **`hswq_AnythingEverywhereTriplet`**：三槽位组合广播节点，用于 MODEL、CLIP、VAE 三元组
- **`hswq_AnythingEverywherePrompts`**：双槽位提示词广播节点，用于正向/反向条件路由
- **`hswq_ComboClone`**：下拉框克隆节点，自动同步所连接目标节点的下拉选项
- **`hswq_SimpleString`**：旧版字符串透传工具节点

### 2. 现代 ComfyUI 前端架构深度适配 (1.52.7+)
集成的 JavaScript 前端扩展（`js/everywhere/`）全面修复了近期 ComfyUI 前端的破坏性变更：
- **`node.comfyClass` 废弃兼容**：在 LiteGraph 节点实例上实现安全的回退判定机制，确保节点类型识别正常
- **`graphToPrompt` 接收者绑定**：显式绑定接收者上下文，彻底消除序列化时的运行时异常
- **悬空链接自动清理**：增强图遍历与连线有效性校验，杜绝工作流提示词序列化时的悬空链接报错

### 3. 前端隔离与零外部依赖
- **CustomElement 自定义标签冲突防护**：将浮动窗口标签重命名为 `<hswq-ue-floating>`，并加入安全构造函数降级回退机制，杜绝多扩展共存时引发的 `TypeError: Illegal constructor` 崩溃。
- **DOM ID 独立命名**：将提示框元素 ID 隔离为 `#hswq_ue_tooltip`，防止样式与 DOM 命名污染。
- **日志调用健壮性**：修正 `Deferred.prototype.execute` 中未引用的日志调用，统一改用原生 `console.error`。
- **零外部依赖**：本插件 100% 独立运行，对 `cg-use-everywhere` 无任何外部导入或代码依赖。
