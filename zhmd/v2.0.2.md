# v2.0.2 - CCSR ConvRot INT8 与 TensorRT 加速

本版本为插件内的 CCSR 增加两条路径：

- **ConvRot INT8 检查点**：既有的 fp16/PyTorch CCSR 节点（`CCSR_Model_Select` / `DownloadAndLoadCCSRModel`）可加载量化的 UNet + ControlNet，权重以 INT8 驻留 VRAM（显存占用约为原来的一半）。
- **TensorRT 加速**：新增两个节点（`LoadCCSRModelTensorRT`、`CCSR_Upscale_TRT`），ControlNet+UNet 的 apply-model 在 TensorRT 引擎上运行（约 1.4 倍于 fp16 PyTorch）。

另外：CCSR 采样器中的 `steps` 现在表示实际扩散步数；README 的节点参考按用途拆分。

---

## 1. 路径划分

| 路径 | 加载器 | 放大节点 | 后端 |
|---|---|---|---|
| fp16 / INT8（PyTorch） | `CCSR_Model_Select` / `DownloadAndLoadCCSRModel` | `CCSR_Upscale` | PyTorch（fp16；量化检查点走 ConvRot INT8） |
| TensorRT | `LoadCCSRModelTensorRT` | `CCSR_Upscale_TRT` | TensorRT 引擎（fp16 构建）+ fp16 VAE/cond_encoder 辅助权重 |

## 2. TensorRT 引擎节点

### 2.1 仅引擎加载

`LoadCCSRModelTensorRT` 不需要完整检查点。它加载：

- **TensorRT 引擎**（`nodes/CCSR/trt_engines/*.rtxplan`）- 由融合的 ControlNet+UNet apply-model（固定 64x64 latent）的 fp32 导出构建，再转换为 fp16 I/O；
- **辅助权重**（`ccsr_trt_aux.safetensors`，与引擎同目录）- fp16 的 VAE + cond_encoder。

引擎下拉框自动列出 `trt_engines/` 下的所有 `*.rtxplan`；辅助文件自动加载。

### 2.2 修复的缺陷

- 引擎改在**当前 CUDA 流**上执行 - 此前使用私有流导致 ComfyUI 图死锁；
- 引擎输出转回**输入 dtype** - 此前因 fp16 I/O 不匹配输出全黑。

### 2.3 步数 / 调度

`steps` 为实际扩散步数：保留 t_max/t_min 频段设计，同时加密调度，使截断后的范围恰好包含 `steps` 个时间步。

## 3. fp16 节点的 ConvRot INT8 支持

INT8 通过 `comfy_quant` 元数据自动识别；图以混合精度算子构建，量化权重以 `QuantizedTensor` 接入，权重在 VRAM 中保持 INT8：

- fp16 检查点：GPU 上约 2.54 GiB
- ConvRot INT8 检查点：GPU 上约 1.40 GiB（417 个量化张量：UNet 282 层 + ControlNet 135 层）

VAE / cond_encoder 保持 fp16。BF16/fp16 检查点走原有路径。

## 4. 变更文件

| 文件 | 变更 |
|---|---|
| `nodes/CCSR/trt_engine.py` | TRT 引擎运行时（当前流执行、输入 dtype 输出） |
| `nodes/CCSR/nodes.py` | `LoadCCSRModelTensorRT`、`CCSR_Upscale_TRT`；fp16 节点 INT8 分支 |
| `nodes/CCSR/ccsr_int8.py` | INT8 识别、算子替换、普通 INT8 Conv2d 加载的 `QuantConv2d` |
| `nodes/CCSR/model/q_sampler.py` | 调度加密：`steps` = 实际步数，保留 t_max/t_min 频段 |
| `md/CHANGELOG.md` / `zhmd/CHANGELOG.md` | v2.0.2 条目（EN / 中文） |

## 5. 使用方法

**TensorRT 路径**

1. 将引擎（`*.rtxplan`）与 `ccsr_trt_aux.safetensors` 放入 `nodes/CCSR/trt_engines/`。
2. 添加 **LoadCCSRModelTensorRT** - 从下拉框选择引擎（辅助权重自动加载），无需检查点输入。
3. 连接到 **CCSR_Upscale_TRT**（tile 512 固定、64x64 latent）并运行。

**fp16 / INT8 路径（接线不变）**

1. 将 CCSR 检查点（fp16 或 ConvRot INT8）放入 `models/unet/`。
2. `DownloadAndLoadCCSRModel` / `CCSR_Model_Select` 通过 `comfy_quant` 自动识别 INT8。
3. 照常连接到 `CCSR_Upscale`。

`steps` 在两条路径上行为一致。
