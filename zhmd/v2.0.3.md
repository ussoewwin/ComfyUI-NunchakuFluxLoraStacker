# v2.0.3 - CCSR 仅保留 TensorRT

本版本将内置的 CCSR 放大器改为**仅 TensorRT**。

fp16 / ConvRot-INT8 的 PyTorch 节点（`CCSR_Upscale`、`CCSR_Model_Select`、
`DownloadAndLoadCCSRModel`）已**移除** - ControlNet+UNet 的 apply-model 在
TensorRT-RTX 引擎上运行（约 1.4 倍于 fp16 PyTorch），这使得 PyTorch 路径
不再必要：TensorRT 比 fp16 或 INT8 的 PyTorch 推理更快且更省显存。

---

## 1. 变更内容

| 之前（v2.0.2） | 之后（v2.0.3） |
|---|---|
| fp16 / INT8 PyTorch 节点：`CCSR_Model_Select`、`DownloadAndLoadCCSRModel`、`CCSR_Upscale` | **已移除** |
| TensorRT 节点：`LoadCCSRModelTensorRT`、`CCSR_Upscale_TRT` | 保留（现在唯一的 CCSR 路径） |
| `nodes/CCSR/.tracking`、嵌套的 `requirements.txt`、`pyproject.toml`、示例工作流 json（kijai 上游残留） | 已清理 |
| README / `nodes/CCSR/readme.md`：同时说明 fp16 与 TRT 两条路径 | 重写为仅 TRT 路径 |

为什么移除 PyTorch 节点？融合的 ControlNet+UNet 在 TensorRT 上比 fp16
PyTorch 约快 1.4 倍，INT8 的 PyTorch 推理也与 fp16 处于同一量级，因此一旦
有了引擎，两条 PyTorch 路径都没有继续保留的必要 - 移除它们也省掉了整套
量化/加载代码路径（`ccsr_int8.py` 的 ops 替换、INT8 检查点处理）的维护成本。

## 2. 保留的 TRT 路径

- **LoadCCSRModelTensorRT** - 仅引擎加载器。从 `nodes/CCSR/trt_engines/*.rtxplan`
  下拉选择引擎（自动列出）；辅助权重（`ccsr_trt_aux.safetensors`，VAE +
  cond_encoder）从同一目录自动加载，无需完整检查点。
- **CCSR_Upscale_TRT** - TRT 加速放大，固定 tile 512（latent 64x64）以匹配
  静态引擎形状；分块 VAE 编解码与颜色校正以 PyTorch fp16 运行。

`steps` 为实际扩散步数：保留 t_max/t_min 频段设计，同时加密调度，使截断
后的范围恰好包含 `steps` 个时间步。

## 3. 变更文件

| 文件 | 变更 |
|---|---|
| `nodes/CCSR/nodes.py` | 移除 `CCSR_Upscale`、`CCSR_Model_Select`、`DownloadAndLoadCCSRModel` 及 INT8 导入路径（约 265 行）；保留 TRT 加载器/放大节点 |
| `nodes/CCSR/.tracking`、`requirements.txt`、`pyproject.toml`、`examples/ccsr_tiled_upscale_kijai_01.json` | 删除（kijai 上游残留） |

| `md/CHANGELOG.md` / `zhmd/CHANGELOG.md` | v2.0.3 条目（EN / 中文） |

## 4. 使用方法

1. 安装 / 更新插件（ComfyUI-Manager 会运行 `install.py`，缺失时安装
   TensorRT-RTX 运行时）。
2. 从 Hugging Face 下载
   <https://huggingface.co/ussoewwin/CCSR-ConvRot-INT8-and-TensorRT-Engine>：
   - `ccsr_apply_f16io.rtxplan` → `nodes/CCSR/trt_engines/`
   - `ccsr_trt_aux.safetensors` → `nodes/CCSR/trt_engines/`
3. 重启 ComfyUI。CCSR 分类下现在只剩两个 TensorRT 节点。
4. 连接 **LoadCCSRModelTensorRT** → **CCSR_Upscale_TRT**，输入图像并运行。
5. 日志中的 `[CCSR-TRT] ...` 行确认引擎路径生效。

> 使用已移除 fp16 节点的旧工作流，需要改接到 TensorRT 加载器 + 放大节点。
