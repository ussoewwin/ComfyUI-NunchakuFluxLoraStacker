# v2.1.2 — 节点类命名空间化（`hswq_` 前缀）：16 个冲突全部消除

本版本将**本包中所有与其它已发布包共用 `class_type` 名称的节点类**统一加上 **`hswq_`** 命名空间前缀，从而消除 ComfyUI-Manager 归属于本包的全部 16 个冲突条目（Florence-2 4 个＋ControlAltAI 系 12 个）。节点行为、控件、分类、输入输出与数据类型**保持不变**。

---

## 1. 变更概览

| 项目 | v2.0.5 及以前 | v2.1.2 |
|---|---|---|
| **Florence-2 类类型（4 个）** | `DownloadAndLoadFlorence2Model` / `DownloadAndLoadFlorence2Lora` / `Florence2ModelLoader` / `Florence2Run`——与 `kijai/ComfyUI-Florence2`、`un-seen/comfyui-tensorops`、`Ltamann/ComfyUI-TBG-ETUR` 同名 | **`hswq_` 前缀**——不再占用上述同名 |
| **ControlAltAI 工具类类型（11＋1 个）** | `FluxSampler`、`FluxUnionControlNetApply`、`BooleanBasic`、`BooleanReverse`、`GetImageSizeRatio`、`IntegerSettings`、`IntegerSettingsAdvanced`、`PerturbationTexture`、`TextBridge`、`TwoWaySwitch`、`ThreeWaySwitch`（另含模块映射内的 `FluxControlNetApply`）——与 `gseth/ControlAltAI-Nodes` 同名 | **`hswq_` 前缀**——台账冲突条目清除 |
| **`MegapixelCalculatorNode`** | 本包自有名称 | **保持不变**——不存在冲突，现有工作流不受影响 |
| **节点行为 / 数据类型** | — | 与 v2.0.5 完全一致（`FL2MODEL`、`PEFTLORA`、`IMAGE`、`MASK`、`STRING`、`JSON` 不变；Florence-2 分支保留 Transformers 5.x 兼容与 Sage Attention 3 支持） |
| **前端脚本** | `js/integer_settings_advanced.js` 匹配 `IntegerSettingsAdvanced` | 改为匹配 `hswq_IntegerSettingsAdvanced`；互斥逻辑未动 |
| **版本元数据** | `2.0.5` | `2.1.2`（`pyproject.toml` / `__init__.py`），已发布至 Comfy Registry |

## 2. 为什么改名——ComfyUI-Manager 的冲突判定

ComfyUI-Manager 以官方注册表台账（`extension-node-map`）判定冲突：一个节点名被多个包注册即计一次冲突。此前本包的台账条目复用了 16 个其它已发布包拥有的名称，因此 Manager 界面显示本包 **16 个冲突**。注册表收录本版本后，本包仅注册没有任何其它已发布包占用的名称，冲突数归零。同名并存也有运行时风险：ComfyUI 保留最后注册者，安装其它 Florence-2 包时本包分支会被静默遮蔽（反之亦然）。

## 5. 未改名节点

`MegapixelCalculatorNode` 保持原类名：它不属于任何其它已发布包在台账中占用的名称，且本机 34 个工作流正在引用。改名只会破坏这些工作流，对消除冲突毫无帮助。

## 6. 工作流迁移

`class_type` 字符串保存在工作流 JSON 内。若工作流仍使用上述旧名称：

1. 从检索菜单重新添加节点（现以 `hswq_<旧名>` 出现；显示名不变的部分照旧），或
2. 在 JSON 中查找替换：`"type": "<旧名>"` 改为 `"type": "hswq_<旧名>"`（API 格式导出还包含 `"class_type"`）。

保留旧名称的工作流若对应他包已安装，将解析为**对方包**的实现——行为可能不同（例如其它 Florence-2 包缺少本分支的 Transformers 5.x / Sage Attention 3 修正）。本机全部工作流已完成迁移。
